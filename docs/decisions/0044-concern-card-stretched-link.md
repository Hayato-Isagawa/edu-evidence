# 0044. トップの悩みカードを stretched link にする(ADR 0030 の決定 2 を上書き)

- 状態: 採用
- 日付: 2026-10-22
- 関連 PR: #(本 ADR と同一 PR で確定)、#793

## 背景

ADR 0030 は、トップページの悩みカード 4 枚が axe の `label-content-name-mismatch`(WCAG 2.5.3 Label in Name)に当たることを把握したうえで、「修正しない」と決めた。理由の 1 つが、このルールが `experimental` タグを持ち、タグ指定の実行では走らないことだった。同じ ADR は「axe が将来 `experimental` を外して既定実行に含めれば `e2e/a11y.spec.ts` が落ちる。そのときは再検討し、見出しだけをリンクにして疑似要素で当たり判定を広げる(stretched link)構造に変える」と予告していた。

axe-core 4.14.0(2026-10-05)の CHANGELOG に「label-content-name-mismatch: Enable rule by default」とある。4.13 のルール定義にあった `experimental` タグは、4.14 で外れている。`@axe-core/playwright` を 4.14 に上げる Dependabot PR #793 で、トップの a11y 監査(light / dark)が 4 ノードの違反で落ちた。

## 検討した選択肢

- **A. stretched link に変える(採用)** — 0030 が予告した形
- B. `e2e/a11y-known-issues.json` にトップの既知違反として足す。監査は緑に戻るが、Level A の指摘を残したまま、同じページに出る新しい同種の違反も見逃す
- C. `AxeBuilder` の `disableRules` でルールごと外す。B と同じ問題が、全ページに広がる
- D. `aria-labelledby` を外す。アクセシブル名がカード内の全テキスト(カテゴリ・見出し・説明・件数)になり、0030 が退けた形に戻る

## 決定

- カードの外枠を `<div data-concern-card class="group relative …">` にし、`<h3>` の中の見出し文字列だけを `<a>` にする。リンクの `::after` を `absolute inset-0` にして、カード全体を当たり判定にする
- hover とフォーカスの見た目はカード全体で保つ。フォーカスのリングは `div` 側で `has-[:focus-visible]` を使って出す
- `aria-labelledby` は使わない。リンクのアクセシブル名は、見出しの文字列そのものになる

## 帰結

- axe 4.14 で、このルールは変更前に違反 4 ノード、変更後は対象外(inapplicable)になった(light / dark とも。対象外になるのは、名前を上書きする `aria-label` / `aria-labelledby` が無くなったため)。ほかの serious / critical の違反は 0 件
- axe は変更後の構造で名前の一致を測らないので、`e2e/home.spec.ts` が、全カードのリンク名が見出しの文字列と一致すること、カテゴリ・説明文・件数・padding の角がそのカードのリンクに当たること、説明文の座標をクリックすると遷移することを見る
- 変更前後で、通常・hover・キーボードフォーカスの各状態の枠線の色・リング・見出しの色・カードの大きさは一致した(light / dark、トランジションを止めて computed style を比較)。カード一覧のスクリーンショットは 320 / 390 / 768 / 1280px で同一だった
- Tab で止まる位置はカード 1 枚につき 1 つのままである。カテゴリ・説明・件数は、リンクの中ではなくリンクの外の本文になる。スクリーンリーダーでの実際の読み上げは確かめていない
- **カードの中にリンクやボタンを足すと、`::after` の下になって押せない。** 足すときは、その要素に `relative z-10` などを付けて重なり順を上げる
- ADR 0030 の決定 1(a11y 監査を light / dark の両方で行う)は変わらない。0030 の状態は「一部撤回(決定 2 を 0044 で上書き)」にする

## 撤回 / 再検討の条件

- axe がこの構造(見出しリンク + 疑似要素)を別のルールで違反と判定するようになったとき
- カードの中に別の操作要素を置く設計に変えるとき(重なり順の扱いを決め直す)
