# 0049. 本文のリンクは平常時も下線で示す

- 状態: 採用
- 日付: 2026-11-24
- 関連 ADR: 0011(ダークモード)、0030(ダークの文字のコントラスト)、0038(印刷)

## 背景

本文のリンク(`.prose-article a` と `.link-underline`)は、下線をホバーしたときだけ出していた。平常時の手掛かりは色だけで、アクセント色と本文色の比は実測で light 2.26:1、dark 1.49:1 だった。指で触る端末にはホバーが無い。

さらに、`global.css` のレイヤ外にあった `a { color: inherit; text-decoration: none; }` が Tailwind のユーティリティ(`@layer utilities`)に必ず勝つため、`class="link-underline text-accent"` の色が効かず、地の文と同じ色になっていた。main `1c6f19e` のビルドを走査すると、地の文の中のリンク 1118 本(280 ページ)すべてが、下線が無いか、地の文と同じ色だった。axe は違反にしなかった(幅 0% の背景画像を「区別あり」と数えるためと見られる。推測)。

## 検討した選択肢

- **本文だけ常時下線(採用)**: 手掛かりが色から独立する。ナビ・フッター・見出し・カードは、置き場所からリンクと分かるので今のまま
- **色の不具合だけ直す**: 色だけの手掛かりが残る
- **すべてのリンクに下線**: 見出しとナビにも付き、要るところとの差が無くなる

## 決定

1. レイヤ外の `a {}` を消す(preflight が同じ既定を持つ。edu-law は元からこの形)。class に書いた色がそのまま効く
2. `main` の中の本文のリンクに、平常時も実線の下線とアクセント色を付ける。ナビ・見出し・記事のヘッダー・目次・カードの題名・等幅の「一覧へ戻る」は対象外。用語ツールチップの点線はそのまま
3. 平常時の線は 1px で、文字の色の 70%。背景との比は両テーマで 3:1 以上を保つ。線は `border-bottom` で描く。ホバーとフォーカスではこの線を消してから、2px の線を左端から右へ引く(動きを減らす設定では動かさない)。どちらも border の箱の下端に置く
4. `e2e/links-and-theme.spec.ts` が、代表ページの地の文のリンクに下線があり色が地の文と違うこと、線の比と引き直し、ナビとフッターに下線が無いことを見る

## 帰結

- 参考文献の多いページの印象が変わる
- `a` に付けた色のユーティリティが効くようになり、目次・タグ・「一覧へ戻る」などの色も class に書いたとおりになる
- `text-decoration` の下線と背景の線では、位置の基準(文字のベースラインと箱の下端)が違い、フォントごとにずれる。border と背景なら同じ箱なのでそろう
- 素の要素セレクタをレイヤ外に書くと、ユーティリティに勝つ(0038 が印刷で避けたのと同じ理由)

## 撤回 / 再検討の条件

- 本文のリンクを色以外の別の手掛かり(アイコンなど)で示すことにしたとき
