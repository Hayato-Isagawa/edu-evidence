# 0030. a11y 監査を light/dark 両テーマで行い、label-content-name-mismatch は修正しない

- 状態: 採用
- 日付: 2026-08-01
- 関連: [`ADR 0024`](0024-visual-regression-testing.md)(視覚変更 PR での VRT)

## 背景

本番の Lighthouse Accessibility が 100 から **96** に下がっていた。原因は `dark:` 変種を伴わない配色で、ダーク背景に対して 4.5:1 を下回っていたことだった。

axe を **21 ページ × light/dark** に流したところ、`color-contrast` 違反が **24 種**見つかった。内訳は **dark 19 / light 5** で、大半がダーク側にしか現れない。

見逃した理由ははっきりしている。`e2e/a11y.spec.ts` も `scripts/a11y-baseline.mjs` も **既定テーマ(light)しか監査していなかった**。ダークモードは片側だけの監査では守れない。

同時に、Lighthouse は `label-content-name-mismatch`(WCAG 2.5.3 Label in Name / Level A)も報告していた。トップページの悩みカード 4 枚が対象で、カード全体が `<a aria-labelledby="(見出しの id)">` になっている。

## 決定

### 1. a11y 監査は light/dark 両方で行う

`e2e/a11y.spec.ts` を両テーマでループさせる(8 → 16 テスト)。以後、配色の追加・変更は両テーマの実測をもって可とし、`text-*` を直書きする場合は `dark:` 変種の要否を必ず判断する。

効果量が負のときの赤は、テーマ変数 `--color-chart-red` を使う。`text-red-600` の直書きはしない。

### 2. `label-content-name-mismatch` は修正しない

理由は 3 つ。

**(a) 規格に照らすと適合していると読める。** WCAG 2.5.3 の趣旨は、音声入力ユーザーが**見えているラベルを発話して**コントロールを操作できることにある。カードの可視ラベルは見出し(例「学級が落ち着かない・荒れている」)であり、アクセシブル名もその見出しである。発話による操作は成立する。axe はリンク内の全テキストをラベルとみなすため、「カード全体をリンクにし、見出しをアクセシブル名にする」パターンでは誤検知が出やすい。

**(b) axe / Lighthouse の扱いが弱い。** このルールは `experimental` タグを持ち、**タグ指定の実行では走らない**(実測: `withTags([...wcag タグ])` では violations / passes / incomplete / inapplicable のどの区分にも現れない。`withRules` で明示指定したときのみ 4 ノードを検出)。Lighthouse は明示的に有効化するが **weight 0** で、スコアには影響しない。

**(c) axe が受け入れる修正は体験を悪化させる。** `aria-labelledby` を外すとアクセシブル名は「カテゴリ + 見出し + 説明 3 行 + 件数」になり、スクリーンリーダーでの読み上げが著しく冗長になる。

## 反対意見

WCAG 2.5.3 は **Level A** である。AA を掲げるサイトが Level A の指摘を残す以上、判断の根拠を示せる状態にしておく必要がある(本 ADR がその役割を負う)。

また axe が将来 `experimental` を外して既定実行に含めれば、`e2e/a11y.spec.ts` が落ちる。そのときは本 ADR を再検討し、**カード全体をリンクにするのをやめ、見出しだけをリンクにして疑似要素で当たり判定を広げる(stretched link)** 構造に変更する。この形なら可視ラベルとアクセシブル名が一致し、読み上げも簡潔なまま、カード全体のクリック領域も保てる。今回それを採らなかったのは、トップページの構造変更と VRT の再ベースラインを伴う一方で、得られる適合性の変化がゼロだからである。

## 影響

- `e2e/a11y.spec.ts` のテスト数が 8 → 16 になる。
- ダークモードの配色が変わるため、VRT にはダーク側の差分が出る(意図した変更)。
- テーマ切替の検証では、**読み込み後に `data-theme` を差し替えてはならない**。`color` / `background-color` のトランジションが走り、axe が遷移途中の中間色を拾って大量の誤検知を出す(実測 31 ノード)。`global.css` には `prefers-reduced-motion` で止まらないトランジションもあるため、`page.addInitScript` で localStorage を先に仕込み、**初回描画から目的のテーマで読み込ませる**。
