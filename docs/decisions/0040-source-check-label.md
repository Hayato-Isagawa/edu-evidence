# 0040. `lastVerified` の表示ラベルを「出典の最終確認」「主な出典の最終確認」にする

- 状態: 採用
- 日付: 2026-09-25
- 関連 PR: #(本 ADR と同一 PR で確定)

## 背景

ADR 0033 は `lastVerified` を「一次ソースとの最終照合日」と定め、表示ラベルを戦略ページは「最終確認」、コラムは「出典の最終確認」とした。

その後 #678 で、照合の単位を `docs/CONTENT_GUIDELINES.md`「lastVerified の運用」に明文化した。ページが根拠として掲げる出典(ページの出典)のどれか 1 つに、1 か所でも当たり直したら更新する。すべての出典を同じ日に確認したとは限らない。

戦略ページの「最終確認」は、何を確認したかを書いていない。ページ全体を照合したようにも読める。

## 検討した選択肢

- **A. 戦略ページは「出典の最終確認」、コラムは「主な出典の最終確認」にする(採用)**
- B. 両方を「主な出典の最終確認」に揃える。戦略ページには全ページに見出し「主な参考研究」がある。ところが「主な参考研究」をページの出典以外で照合しただけでは更新しない。「主な出典」と読み違えると、言い過ぎが形を変えて残る
- C. 据え置く。戦略ページの「最終確認」が、ページ全体の確認に読める問題が残る

## 決定

- 戦略ページの kicker: `Strategy — 出典の最終確認 YYYY-MM-DD`。kicker の真横に EEF / 日本研究 / Hattie のバッジがあり、出典についての日付だと目で分かる(どの出典を照合したかまでは分からない)
- コラムの日付の列: `主な出典の最終確認: YYYY年M月D日(曜)`。コラムのページの出典は「参考資料のうち本文の数値や結論の根拠になっているもの」なので、「主な」が合う
- 引用文(`src/lib/citation.ts`)は「出典の最終確認 YYYY-MM-DD」のまま変えない。戦略ページとは一致する。コラムだけは見出しと語が 1 つずれるが、引用文は区分を短く並べる形式なので許容する
- ラベルだけでは「1 か所でも当たり直したら更新する」ことは伝わらない。FAQ(`src/data/faq.ts`)に、すべての出典を同じ日に確認したとは限らないことを書く

## 帰結

- 読者は、日付が本文全体ではなく出典の確認の日だと読み取れる。ただし日本語は数を区別しないので、「すべての出典を確認した」と読む余地は残る。そのため FAQ で補う
- 戦略ページの kicker が 3 文字長くなり、320〜360 幅でラベルや日付の途中で割れた。そこで「出典の最終確認」と日付をそれぞれ `whitespace-nowrap` で囲み、単位の境目でだけ折り返すようにした(2 バッジのページの 320 幅では 3 行になる)

### 訂正

ADR は不変とする運用のため、旧 ADR は書き換えず本 ADR で訂正する。

| 箇所 | 訂正 |
|---|---|
| ADR 0033「戦略ページ: `最終更新 YYYY-MM-DD` → **`最終確認 YYYY-MM-DD`**」 | 本 ADR 以降は `出典の最終確認 YYYY-MM-DD` |
| ADR 0033「コラム: `最終更新: YYYY年M月D日` → **`出典の最終確認: YYYY年M月D日`**」 | 本 ADR 以降は `主な出典の最終確認: YYYY年M月D日(曜)` |
| ADR 0033「戦略ページは `Strategy — 最終確認 …` という kicker の文脈で『何の確認か』が読み取れる」 | kicker の文脈だけでは読み取れない。読み取れるのは、隣のバッジが出典を示しているため |

### 対象外

照合日を「更新」と見せる箇所は、表示ラベルの外にも残っている。コラム一覧とトップページの「(更新)」表示、RSS の `pubDate`、JSON-LD の `dateModified` である。本 ADR では扱わず、#679 で扱う。

## 撤回 / 再検討の条件

- `lastVerified` を出典ごとに持つようにした場合(ラベルに出典名を出せるようになる)
- 戦略ページの見出し「主な参考研究」の名前を変えた場合(B を再検討する)
